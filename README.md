Hi! I’m lazarus0734. 
I’m developing a small program called "snowflakes" that adds snow falling from the sky,
which then settles on your windows and taskbar. 
The project is still in an early, rough state, so you might encounter some bugs. 
Please note that the program likely won’t work if you use multiple monitors, have two taskbars, 
or use a custom taskbar replacement. It requires Windows 10 or later.
I can’t guarantee that I’ll continue working on this project in the future, but it is completely open-source,
so feel free to edit it yourself. Enjoy!
